# Ручная проверка сценариев

Автотестов фронтенда нет, поэтому перед релизом прогоняется этот чек-лист.

## Подготовка

1. Запустить бэкенд, Redis и фронт (см. `server/context/dev-guide.md`).
2. Заполнить базу: `python manage.py seed_data`.
3. Аккаунты: преподаватели `teacher1`, `teacher2`; студенты `student1`–`student3`.
   Пароль у всех — `password123`.

## Доступ по ролям

| Страница | Гость | Студент | Преподаватель |
| :--- | :--- | :--- | :--- |
| `/`, `/courses`, `/courses/[slug]` | ✅ | ✅ | ✅ |
| `/auth/login`, `/auth/register` | ✅ | → `/profile` | → `/profile` → `/teacher` |
| `/learning`, `/learning/grades` | → login | ✅ | → `/learning` (отказ) |
| `/learning/[course]/…` | → login | ✅ если записан, иначе → страница курса | — |
| `/teacher/**` | → login | → `/learning` | ✅ |

## Аутентификация

- [ ] Регистрация: валидация email, совпадение паролей, сложность пароля; после успеха — автологин.
- [ ] Вход: неверные данные → сообщение об ошибке; верные → переход в профиль.
- [ ] «Оставаться в системе»: после перезапуска браузера сессия сохраняется.
- [ ] Перезагрузка защищённой страницы не выбрасывает на логин.
- [ ] Выход очищает сессию; защищённые страницы снова требуют вход.

## Каталог

- [ ] Поиск, фильтры по категории и сложности, сортировка; параметры попадают в URL.
- [ ] Смена фильтра сбрасывает страницу на 1; ссылка с параметрами открывает тот же результат.
- [ ] Пустой результат показывает пустое состояние.
- [ ] Запись на курс: toast, кнопка меняется на «Перейти к курсу», курс появляется в кабинете.

## Студент

- [ ] Кабинет: мои курсы, последние оценки, работы на проверке.
- [ ] Курс: прогресс, статистика, список уроков.
- [ ] Урок: материал, задания к уроку, переход к следующему уроку, комментарии и ответы на них.
- [ ] Задание: инструкции, дедлайн (просроченный подсвечен), отправка текста и файлов
      (drag & drop); после отправки статус «На проверке».
- [ ] Оценки: список и статистика (средний, лучший, минимальный балл), комментарии преподавателя.

## Преподаватель

- [ ] Панель: счётчики, очередь проверки, мои курсы.
- [ ] Курс: создание (валидация, черновик/публикация), редактирование, удаление.
- [ ] Уроки и задания: создание, редактирование, удаление, порядок.
- [ ] Студенты курса: список записанных.
- [ ] Проверка работ: фильтр по статусу, пагинация; оценка от 0 до `max_score` с комментарием;
      после сохранения статус «Оценено».

## Общее

- [ ] Адаптив: 1920×1080, 768×1024, 375×667 (меню-гамбургер, сетка карточек, формы, таблицы).
- [ ] Скелетоны при загрузке, индикатор загрузки на кнопках отправки.
- [ ] Ошибки API показываются в toast; несуществующий маршрут — страница 404.
- [ ] Уведомления: счётчик непрочитанных, отметка «прочитано».
- [ ] Светлая и тёмная темы.
