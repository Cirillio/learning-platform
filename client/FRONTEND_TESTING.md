## Предварительные требования

### Окружение

- **Backend**: Django API запущен на `http://localhost:8000`
- **Frontend**: Nuxt dev server запущен на `http://localhost:3000`
- **База данных**: Заполнена тестовыми данными (категории, курсы)

### Тестовые аккаунты

1. **Студент**:

   - Username: `test_student`
   - Email: `student@test.com`
   - Password: `TestPass123`

2. **Преподаватель** (создаётся через Django Admin):
   - Username: `test_teacher`
   - Email: `teacher@test.com`
   - Password: `TestPass123`

## 1. Аутентификация

### 1.1 Регистрация студента

**Путь**: `/auth/register`

**Предусловия**: Пользователь не авторизован

**Шаги**:

1. Открыть `/auth/register`
2. Заполнить форму:
   - Имя: `Тестовый`
   - Фамилия: `Студент`
   - Имя пользователя: `new_student_test`
   - Email: `newstudent@test.com`
   - Пароль: `SecurePass123`
   - Подтверждение пароля: `SecurePass123`
3. Нажать "Зарегистрироваться"

**Ожидаемый результат**:

- ✅ Появляется информационный баннер о регистрации только для студентов
- ✅ После успешной регистрации — редирект на главную страницу
- ✅ Пользователь авторизован (видно имя в header)
- ✅ Роль пользователя: `student`

**Проверка ошибок**:

- [ ] Пустые обязательные поля → ошибки валидации
- [ ] Неверный формат email → ошибка "Неверный формат email"
- [ ] Пароли не совпадают → ошибка "Пароли не совпадают"
- [ ] Слабый пароль (без заглавных/цифр) → ошибка валидации

---

### 1.2 Авторизация (Login)

**Путь**: `/auth/login`

**Предусловия**: Существует зарегистрированный пользователь

**Шаги**:

1. Открыть `/auth/login`
2. Ввести `username` и `password`
3. Опционально: включить "Запомнить меня"
4. Нажать "Войти"

**Ожидаемый результат**:

- ✅ Редирект на `/dashboard` (для студентов) или `/teacher/dashboard` (для преподавателей)
- ✅ В header отображается имя пользователя
- ✅ Cookies `access_token`, `refresh_token` установлены (httpOnly)

**Проверка ошибок**:

- [ ] Неверный логин/пароль → "Неверные учетные данные"
- [ ] Пустые поля → ошибки валидации

---

### 1.3 Выход (Logout)

**Путь**: Кнопка в header → "Выйти"

**Предусловия**: Пользователь авторизован

**Шаги**:

1. Нажать на аватар/меню пользователя в header
2. Выбрать "Выйти"

**Ожидаемый результат**:

- ✅ Редирект на главную страницу `/`
- ✅ Cookies удалены
- ✅ Попытка зайти на защищённые страницы → редирект на login

## 2. Каталог курсов

### 2.1 Просмотр каталога

**Путь**: `/courses`

**Предусловия**: Нет

**Шаги**:

1. Открыть `/courses`

**Ожидаемый результат**:

- ✅ Отображается список опубликованных курсов
- ✅ Каждая карточка курса содержит:
  - Название
  - Краткое описание
  - Имя преподавателя
  - Категория
  - Уровень сложности
  - Количество записанных студентов
- ✅ Hero-секция с поиском

---

### 2.2 Фильтрация и сортировка

**Путь**: `/courses`

**Шаги**:

1. Открыть `/courses`
2. Выбрать фильтр по категории (dropdown "Категория")
3. Выбрать фильтр по сложности (dropdown "Сложность")
4. Выбрать сортировку (dropdown "Сортировка")
5. Проверить URL query parameters

**Ожидаемый результат**:

- ✅ URL обновляется: `/courses?category=programming&difficulty=beginner`
- ✅ Список курсов фильтруется согласно выбору
- ✅ При перезагрузке страницы фильтры сохраняются
- ✅ Кнопка "Сбросить" очищает все фильтры

---

### 2.3 Поиск курсов

**Путь**: `/courses`

**Шаги**:

1. Открыть `/courses`
2. Ввести текст в поле поиска (например: "Python")
3. Нажать "Найти" или Enter

**Ожидаемый результат**:

- ✅ URL обновляется: `/courses?search=Python`
- ✅ Отображаются только курсы, содержащие "Python" в названии/описании
- ✅ Кнопка очистки (X) удаляет поисковый запрос

---

### 2.4 Пагинация

**Путь**: `/courses` (если курсов > 9)

**Шаги**:

1. Открыть `/courses`
2. Пролистать до пагинации внизу страницы
3. Нажать на номер страницы или стрелки навигации

**Ожидаемый результат**:

- ✅ URL обновляется: `/courses?page=2`
- ✅ Отображается соответствующая страница курсов
- ✅ Показано общее количество и диапазон текущих элементов

- ✅ Блок последних оценок

**Предусловия**: Авторизован как студент, не записан на курс

**Шаги**:

### 3.3 Просмотр курса (Learning)

**Путь**: `/learning/{course_slug}`

- ✅ Hero-карточка с информацией о курсе

---

### 3.4 Просмотр урока

**Предусловия**: Авторизован как студент, записан на курс

**Ожидаемый результат**:

- ✅ Заголовок и описание урока
- ✅ Видео (если есть)
- ✅ Текстовый контент урока
- ✅ Материалы для скачивания (если есть)
- ✅ Навигация между уроками

---

### 3.5 Сдача задания

**Путь**: `/learning/{course_slug}/assignments/{assignment_id}`

**Предусловия**: Авторизован как студент, есть несданное задание

2. Выбрать задание
3. Заполнить текстовый ответ
4. Опционально: прикрепить файлы
5. Нажать "Отправить"

**Ожидаемый результат**:

- ✅ Toast "Задание сдано!"
- ✅ Статус изменился на "На проверке"
- ✅ Форма заблокирована для редактирования (до оценки)

---

### 3.6 Просмотр оценок

**Путь**: `/learning/grades`

**Предусловия**: Авторизован как студент, есть проверенные работы

**Шаги**:

1. Перейти в `/learning/grades`

**Ожидаемый результат**:

- ✅ Статистика: всего оценок, средний балл, лучший/худший балл

## 4. Функционал преподавателя

### 4.1 Панель преподавателя

**Путь**: `/teacher/dashboard`

**Предусловия**: Авторизован как преподаватель

**Шаги**:

1. Авторизоваться как преподаватель
2. Перейти на `/teacher/dashboard`

**Ожидаемый результат**:

- ✅ Приветствие с именем
- ✅ Статистика: курсы, студенты, работы на проверке, опубликованные курсы
- ✅ Список недавних работ на проверке
- ✅ Список своих курсов в sidebar

---

### 4.2 Создание курса

**Путь**: `/teacher/courses/create`

**Предусловия**: Авторизован как преподаватель

**Шаги**:

1. Перейти в `/teacher/courses`
2. Нажать "Создать курс"
3. Заполнить форму:
   - Название
   - Краткое описание
   - Полное описание
   - Категория
   - Сложность
   - Длительность (недели)
   - Макс. студентов
   - Статус (черновик/опубликован)
   - Обложка (опционально)
4. Нажать "Создать курс"

**Ожидаемый результат**:

- ✅ Toast "Курс создан!"
- ✅ Редирект на страницу управления курсом `/teacher/courses/{slug}`
- ✅ Курс появляется в списке курсов преподавателя

---

### 4.3 Управление курсом

**Путь**: `/teacher/courses/{slug}`

**Предусловия**: Авторизован как преподаватель, курс существует

**Шаги**:

1. Перейти в `/teacher/courses/{slug}`

**Ожидаемый результат**:

- ✅ Header с информацией о курсе
- ✅ Статистика курса
- ✅ Табы: Уроки, Задания, Студенты, Статистика
- ✅ Кнопки "Редактировать" и "Добавить урок"

---

### 4.4 Создание урока

**Путь**: `/teacher/courses/{slug}/lessons/create`

**Предусловия**: Авторизован как преподаватель, курс существует

**Шаги**:

1. В управлении курсом нажать "Добавить урок"
2. Заполнить форму:
   - Название
   - Описание
   - Контент (текст/markdown)
   - URL видео (опционально)
   - Длительность
   - Материалы (файлы)
   - Статус публикации
3. Нажать "Создать урок"

**Ожидаемый результат**:

- ✅ Toast "Урок создан!"
- ✅ Урок появляется в списке

---

### 4.5 Создание задания

**Путь**: `/teacher/courses/{slug}/assignments/create`

**Предусловия**: Авторизован как преподаватель, курс и уроки существуют

**Шаги**:

1. В управлении курсом → таб "Задания" → "Добавить задание"
2. Заполнить форму:
   - Привязка к уроку
   - Название
   - Описание
   - Инструкции
   - Макс. балл
   - Дедлайн
   - Обязательное/необязательное
   - Разрешена поздняя сдача
3. Нажать "Создать задание"

**Ожидаемый результат**:

- ✅ Toast "Задание создано!"
- ✅ Задание появляется в списке

---

### 4.6 Просмотр списка студентов курса

**Путь**: `/teacher/courses/{slug}` → Таб "Студенты"

**Предусловия**: Авторизован как преподаватель, на курс записаны студенты

**Шаги**:

1. Перейти в `/teacher/courses/{slug}`
2. Переключиться на таб "Студенты"

**Ожидаемый результат**:

- ✅ Таблица студентов: имя, email, дата записи, прогресс
- ✅ Бейдж с количеством студентов
- ✅ Кнопка обновления списка

---

### 4.7 Проверка работ (Grading)

**Путь**: `/teacher/grading`

**Предусловия**: Авторизован как преподаватель, есть работы на проверке

**Шаги**:

1. Перейти в `/teacher/grading`
2. Использовать фильтры (статус: ожидает/проверено)
3. Нажать на работу для детального просмотра

**Ожидаемый результат**:

- ✅ Список всех работ с фильтрацией
- ✅ Пагинация
- ✅ Информация: студент, задание, дата отправки, статус

---

### 4.8 Выставление оценки

**Путь**: `/teacher/grading/{submission_id}`

**Предусловия**: Авторизован как преподаватель, есть работа на проверке

**Шаги**:

1. Перейти в `/teacher/grading/{submission_id}`
2. Просмотреть ответ студента и прикреплённые файлы
3. Ввести оценку (0 - max_score)
4. Опционально: добавить комментарий
5. Нажать "Выставить оценку"

**Ожидаемый результат**:

- ✅ Toast "Оценка выставлена"
- ✅ Статус работы изменился на "Проверено"
- ✅ Панель оценки показывает выставленные данные

## 5. Общие проверки

### 5.1 Role-Based Access Control

| Страница           | Студент      | Преподаватель         | Гость    |
| ------------------ | ------------ | --------------------- | -------- |
| `/`                | ✅           | ✅                    | ✅       |
| `/courses`         | ✅           | ✅                    | ✅       |
| `/auth/login`      | ➡️ dashboard | ➡️ dashboard          | ✅       |
| `/dashboard`       | ✅           | ➡️ /teacher/dashboard | ➡️ login |
| `/learning/*`      | ✅           | ❌                    | ➡️ login |
| `/learning/grades` | ✅           | ❌                    | ➡️ login |
| `/teacher/*`       | ❌           | ✅                    | ➡️ login |

**Легенда**: ✅ Доступ, ❌ Нет доступа, ➡️ Редирект

---

### 5.2 Responsive Design

**Проверить на**:

- [ ] Desktop (1920x1080)
- [ ] Tablet (768x1024)
- [ ] Mobile (375x667)

**Элементы для проверки**:

- [ ] Header — hamburger menu на мобильных
- [ ] Каталог курсов — адаптивная сетка карточек
- [ ] Формы — полноширинные на мобильных
- [ ] Таблицы — горизонтальный скролл или альтернативное представление
- [ ] Sidebar в learning/teacher layouts — collapsible

---

### 5.3 Loading States

- [ ] Скелетоны при загрузке списков
- [ ] Loading индикаторы на кнопках при отправке форм
- [ ] Корректная обработка медленного соединения

---

### 5.4 Error Handling

- [ ] Toast уведомления при ошибках API
- [ ] Страница ошибки 404 для несуществующих маршрутов
- [ ] Graceful degradation при недоступности backend

---

### 5.5 Уведомления (Notifications)

**Путь**: Header → Колокольчик

**Проверить**:

- [ ] Счётчик непрочитанных уведомлений
- [ ] Список уведомлений (dropdown/страница)
- [ ] Пометка как прочитано

## Заметки

- **Создание преподавателя**: API не поддерживает публичную регистрацию преподавателей. Используйте Django Admin (`/admin/`) для назначения роли `teacher`.
- **Токены**: Авторизация использует httpOnly cookies, обновление токенов происходит автоматически.
- **Тестовые данные**: Для полноценного тестирования рекомендуется использовать `fixtures` или создать данные через API/Admin.
